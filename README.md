# Turnierplaner Fußball

Interaktiver Spielplan für das Schulfußballturnier. Läuft im Browser und nach dem ersten Öffnen auch offline (zum Beispiel auf dem iPad über „Zum Home-Bildschirm“). Alle Eingaben werden nur auf dem jeweiligen Gerät gespeichert.

Adresse: https://luki484703.github.io/turnierplaner/
